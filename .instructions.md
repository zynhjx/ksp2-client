# KSP Client - Development Instructions

## Project Overview
This application is built for SK planning and community improvement. Youth users register through the product, their profile and activity data is stored in the database, and the SK dashboard surfaces that data as analytics.

This rebuild uses Next.js 16, Tailwind CSS v4, and shadcn/ui components to create a modern dashboard experience for SK and later admin users.

---

## Platform Domains & Origins
- **Development origin:** `https://kabataanprofile.test`
- **Production origin:** `https://kabataanprofile.com`
- **SK user access:** via the SK subdomain
- **Admin access (future):** via an admin subdomain

Normal users and SK users share the main origin, while SK and admin routes are served on dedicated subdomains.

## Tailwind CSS & Styling Rules

### Theme Colors
**Always use these defined theme colors from `globals.css`:**
- `--color-theme-dark-blue`: #223e9e (primary brand color)
- `--color-theme-white`: #F9FAFB (background/text color)
- `--color-theme-blue`: #160076 (secondary)
- `--color-theme-card-white`: #FFFFFF (card backgrounds)
- `--color-theme-card-border`: #E5E7EB (card borders)

### Tailwind Usage
1. **Use Tailwind utility classes** for all styling - no new plain CSS classes
2. **Reference theme colors via Tailwind's color system:**
   ```tsx
   // ✅ Correct
   <div className="bg-theme-dark-blue text-theme-white">
   <button className="bg-theme-dark-blue hover:opacity-90">
   
   // ❌ Avoid
   <div style={{backgroundColor: "#223e9e"}}>
   <div className="custom-blue-class">
   ```

3. **Use `clsx` and `cn()` for conditional classes:**
   ```tsx
   import clsx from 'clsx';
   import { cn } from '@/lib/utils';
   
   <div className={cn("p-4", isActive && "bg-theme-dark-blue")}>
   ```

4. **Responsive design with Tailwind prefixes:**
   ```tsx
   <div className="sm:flex md:grid lg:flex-row xl:gap-8">
   ```

## Component Conventions

### File Structure
- **UI Components**: `components/ui/` - shadcn/ui and reusable primitives
- **Auth Components**: `components/auth/` - authentication-related
- **Client Components**: `components/client/` - client-side specific logic
- **Feature Components**: `components/` - domain-specific components

### Component Templates

**Server Component (default):**
```tsx
// components/Example.tsx
export default function Example({ prop }: Props) {
  return (
    <div className="bg-theme-white p-4 rounded-lg border border-theme-card-border">
      Content
    </div>
  );
}
```

**Client Component (when needed):**
```tsx
"use client";

import { useState } from 'react';

export default function Example({ prop }: Props) {
  const [state, setState] = useState();
  
  return (
    <div className="bg-theme-white">
      {state}
    </div>
  );
}
```

### Button Component
Always use the Button component from `components/ui/button.tsx` (shadcn/ui):
```tsx
import { Button } from "@/components/ui/button";

<Button className="bg-theme-dark-blue">Action</Button>
<Button variant="outline" className="border-theme-card-border">Cancel</Button>
```

## Development Workflow

### Starting Development
```bash
npm run dev
# Opens on http://localhost:3000
```

### Creating Components
1. Create new component file in appropriate `components/` subdirectory
2. Use Tailwind classes with theme colors
3. Extract to `components/ui/` if reusable across features
4. Use TypeScript for type safety

### Styling New Pages
1. Use layout/page structure in `app/`
2. Create feature components in `components/`
3. Apply theme colors consistently
4. Test responsive behavior (sm, md, lg breakpoints)

---

## Do's and Don'ts

✅ **DO:**
- Use theme colors from `globals.css` (@theme)
- Compose components from shadcn/ui
- Keep components focused and single-responsibility
- Use Tailwind's responsive utilities
- Leverage server components by default

❌ **DON'T:**
- Create new plain CSS files (use Tailwind only)
- Hardcode colors - use theme variables
- Mix styling approaches (no CSS-in-JS, inline styles)
- Create duplicate components when shadcn/ui exists
- Break the theme color system
